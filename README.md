# Line Follower Bot

An early Arduino hardware project: groundwork for a line-following robot.

## What's here

- `servo_motor.30sept/servo_motor.30sept.ino` - demo sketch that sweeps a servo (pin 3) through 0°, 90° and 180°. Used to test motor control before building the line-following logic.

The line-following algorithm itself has not been added to this repository yet.

## Hardware

- Arduino board
- Servo motor on digital pin 3

## Running the sketch

1. Open the `.ino` file in the Arduino IDE.
2. Select your board and port.
3. Upload. Open the Serial Monitor at 9600 baud to see output.
